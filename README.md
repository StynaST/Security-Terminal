AE2 Security Terminal
=======

<span style="color:#3598db">AE2 Security terminal is a simple mod that ports the security terminal to all versions ae2 on 1.20.1+ since they removed it.</span>

<span style="color:#3598db">will block all interactions with the AE2 System if you do not have sufficient permission, and will even block stuff like cardboard boxxing it to bypass the security. also blocks breaking the terminal aswell (was the main issue with the security terminal before as u could just bypass everything by breaking / moving it)</span>

<span style="color:#ba372a">wireless stuff will stay on the WAP instead of being moved to this security terminal.&nbsp;</span>
